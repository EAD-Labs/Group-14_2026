# MLX Studio

MLX Studio is an interactive machine learning app for a college course. This build covers only two topics: Linear Regression and K-Means.

## Tech stack

- Vite and React
- No backend
- React Router for navigation
- Plain CSS custom properties for styling
- Raw SVG for charts
- `useState` for state
